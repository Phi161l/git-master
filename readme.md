# Git Practice Project

## Overview

This project is a simple practice repo used to understand Git concepts step by step.

## What I learned

### 1. Branching

* Creating branches like `feature-1` and `feature-1.1`
* Switching between branches
* Understanding branch pointers

### 2. Commits

* Each commit is a full snapshot of the project
* Commits form the history graph

### 3. Merging

* Merging combines two branch histories
* Fast-forward merge moves the branch pointer forward
* Real merge creates a merge commit when branches diverge
* Conflicts happen when same lines are changed in both branches

### 4. Conflict Resolution

* Git shows conflict markers
* Developer manually chooses final code
* Then commits the resolved merge

### 5. Tags

* Tags are fixed pointers to commits
* Used for versions like `v1.0`
* Commonly used for releases and deployments

### 6. GitHub Remote

* `origin/main`, `origin/feature` are remote-tracking branches
* They represent the state of branches on GitHub

## Conclusion

This project helped understand how Git tracks history, branches, merges, and versions in real development workflows.
